方程复习卡

一元一次方程示例：2x + 3 = 11

一、题目

解方程：

2x + 3 = 11

其中 x 是未知数。目标是把 x 单独留在等号一边，得到“x = 几”的形式。

二、解题过程

  1. 看清左边：2x 表示“2 乘 x”，再加 3，结果是 11。 这里 x 只出现一次，且最高次数是 1，所以是一元一次方程。
  2. 第一步：两边同时减去 3，把常数 3 消掉。 原式2x + 3 = 11 减 32x + 3 − 3 = 11 − 3 化简2x = 8 依据：等式两边同时减去同一个数，等式仍然成立。
  3. 第二步：两边同时除以 2，把 x 前面的系数化为 1。 除以 22x ÷ 2 = 8 ÷ 2 化简x = 4 依据：等式两边同时除以同一个不为 0 的数，等式仍然成立。
三、检验（把 x = 4 代回原方程） 左边2 × 4 + 3 = 8 + 3 = 11 右边11

左边 = 右边，所以 x = 4 是原方程的解。

答案：x = 4

四、方法小结

步骤要消去的部分使用的运算结果
第 1 步左边的“+ 3”两边同时减 32x = 8
第 2 步x 前面的“× 2”两边同时除以 2x = 4
结尾—代入原方程检验左边 = 11 = 右边

五、易错提醒

  • 两边要同时做同样的运算，不能只改一边。
  • 减 3 时，右边的 11 也要减 3，写成 11 − 3，而不是保持不变。
  • 2x = 8 中，x 不是 8，因为 x 被乘了 2；要除以 2 才得 x = 4。
  • 算完把答案代回原方程检查，可以快速发现计算错误。

六、同类练习（可自测）

  • 2x + 3 = 13 → 两边减 3 得 2x = 10，再除以 2 得 x = 5。
  • 3x − 2 = 10 → 两边加 2 得 3x = 12，再除以 3 得 x = 4。
  • 5x + 1 = 11 → 两边减 1 得 5x = 10，再除以 5 得 x = 2。
