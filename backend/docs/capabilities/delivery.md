# 交付清单与验收历史

概览 `deliverables` 汇总本任务及子任务保存的全部文件版本，以及本任务验收引用的历史版本。每项包含 artifactId、fileId、version、来源 ID 和链接、格式、大小、SHA-256、实际下载入口、结构验证与验收状态。

`passed` 表示该具体版本被持久验收记录接受；`failed` 表示关联交付未通过验收；`unverified` 表示尚无完整验收。成功写入文件的格式检查只属于结构验证，不被冒充为完成任务的验收。任务失败或取消不会删除已保存文件。

`finish` 读取真实文件、进行现有格式／内容／来源检查，然后模型审核，最多两轮修复。每条 `validation` 保存 operation ID、具体 artifact/file/version 引用、结论、问题和时间。已保存验收的 operation 重放时重用原结论和版本，不重跑审核、不因最新产物变化覆盖历史。最终任务结果中的下载入口也绑定经过检查的文件。

产物后续修订写入新版本；旧任务的交付、下载和验收记录仍指向原文件。只有实际文件元数据才能进入清单；输出声明失败、缺失或不合法的文件不会被当作已交付。

限制：模型审核是内容评估，不能当作形式化正确性证明；`passed` 记录可能携带非阻断的审核提示。旧任务没有新增验收记录时显示未验证，不推断它们历史上是否通过。验收尚未发生或模型审核中断时，已保存文件仍可下载，显示未验证。

验收：通过与失败记录、文件版本锁定、下载、重复 operation、后续修订不改变历史、真实模型资料整理和代码产物。证据和依赖状态见总验收记录。
