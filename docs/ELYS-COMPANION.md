# Elys 个人分身、记忆库与自聊

Hyperagent 现有 Node/SQLite 界面新增侧栏 **分身与记忆**，路径 `/companion`。启动原来的 `npm run dev` 或生产服务后，在当前工作区创建个人分身，保存交流方式，再进入自聊。自聊使用现有的模型配置、durable run、事件重连和服务器保存机制。

这次接入使用 Hyperagent 自身的 workspace、agent、thread、memory 数据，不连接或导入独立 Elys 服务中的三位演示用户。不同工作区分别管理各自的分身与记忆。`backend/` 的 PostgreSQL `/api/v1` 界面尚未接入此页。

## 使用流程

1. 创建个人分身，填写名字、介绍与交流方式。
2. 在自聊发送消息。点本人消息旁的 **整理为记忆**，或回到分身页使用 **从自聊整理**，选择原话并手动整理成候选；也可以直接添加候选。
3. 保存的候选默认仅用于自聊，必须点 **确认** 才会进入后续模型上下文。可编辑、拒绝、撤回、重新整理或删除。
4. 已确认记忆按话题相关性检索，口吻类作为交流风格提供。回答下方的 **本轮提供的分身记忆** 展示服务器保存的实际内容快照，包括为模型预算裁剪后的文字。

本轮实现的是手动从原话整理候选；自动模型提取、旧记忆冲突合并、成长评分与社交动态暂未接入。

## 记忆范围与历史

`pending / active / rejected` 分别表示待确认、已确认、已拒绝。候选与拒绝项不会作为记忆资源提供给模型；`pinned` 或显式选中也不能绕过状态和范围校验。私有记忆只供相同分身的有效自聊使用；“该分身的其他聊天”允许相同分身在普通线程使用该条已确认内容，不等于发布到公网。

同一条记忆保留最近 50 次操作快照。来源来自当前分身自聊中的真人消息，保留原话片段，排除 assistant 回复。删除来源自聊后，已保存的原话快照仍可核对。删除记忆会删除它的操作历史；已完成回答中的使用快照继续保留。

编辑、撤回和范围调整作用于之后创建的运行；已经开始的运行持有此前授权的上下文。模型可能从当前会话原话或旧回答中再次看见同一事实，因此撤回长期记忆不等于清除历史聊天。

普通 Memories 管理页与手动上下文选择器不会把这些记忆转成普通全局记忆。服务端的资源搜索、分页读取、文档、表格与附件读取同样检查范围，阻止普通线程或子任务绕过自聊限制。删除自聊会同时删除其关联产物，避免解绑后改变可读取范围；界面在删除前明确说明。

## 模型与存储

DeepSeek 最多选取 4 条记忆，在 UTF-8 字节预算内保留内容。SCNet 为当前小模型单独保留分身设定与最多 2 条记忆：设定不超过 400 字节，记忆正文合计不超过 500 字节。桥接层将这些片段保留到实际模型请求，使用快照记录同样的片段；请求仍然过大时明确失败。

新增字段保存在现有 SQLite workspace 快照中，继续使用原登录会话、CSRF 与 `If-Match` 版本冲突检测，无需新增数据库、外部密钥或修改 Elys 的数据库。分享线程仍须在原分享对话框确认，分享快照不附带记忆库、来源元数据或 knowledge hints。

## 验证

```sh
node --test server/companion-memory.test.mjs server/companion-tools.test.mjs server/companion-flow.test.mjs
npm run typecheck
npm run build
node scripts/verify-companion-ui.mjs
```

HTTP 集成测试使用临时 SQLite、真实认证与 managed run，并向受控 provider 检查实际请求内容和最终保存。SCNet 适配测试检查实际发出的 HTTP 请求体。浏览器验收同样使用隔离数据与合成模型，不代表生产 SCNet 远程推理验收，也不新开 DCU 作业。

验收记录：[后端 454 项回归与构建](verification-companion/backend.json)、[浏览器流程与桌面/手机截图](verification-companion/results.json)。受管理环境中，测试使用 `--test-isolation=none` 并显式列出测试路径，避免测试子进程的本机端口监听限制。
