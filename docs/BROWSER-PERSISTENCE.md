# 持久浏览器与中断任务续接

侧栏 **浏览器** 打开 `/browser` 工作台。这里的会话与聊天中的 Browser 工具共用同一工作区身份。可输入网址，使用标签页与前进、后退、刷新；登录时接管浏览器，完成后交还。刷新网页会恢复所选会话和缩放。

Agent 新增 `browser_click`、`browser_fill`、`browser_press`、`browser_scroll`、`browser_history`、`browser_switch_tab`。观察返回当前控件引用，下一步操作使用实际返回的引用。页面变化、控制权变更或旧观察会阻止过时操作，要求重新观察。密码、验证码和支付字段留给用户在接管画面中输入。

网站需要登录、注册或验证时，Agent 调用 `browser_request_takeover` 后，主会话显示 **等待你操作浏览器**。点击 **打开等待中的浏览器** 会打开本次任务请求的实际会话；小屏幕的 **点击开始操作** 或固定操作条的 **接管浏览器** 都会取得人控；完成网站操作后点击 **交还 AI**。画面可直接点击和键盘输入，支持中文与粘贴，画面下方也有辅助输入框。关闭查看器或刷新聊天不会交还控制权。等待期间不会请求下一轮模型回复，交还后先取得同一会话的新页面观察再继续。

等待和交还事件写入任务事件日志，刷新聊天可重放等待提示。人工等待不消耗模型执行的 active 计时；交还后恢复剩余执行预算。SCNet 默认等待至当前模型服务的截止时间，最多 5 小时；其他 provider 默认 30 分钟。显式 timeoutSeconds 覆盖仍限制在 600 秒以内。超时、取消或未确认交还会停止本次任务并保留浏览器的人控状态。应用服务重启会将运行标为中断，需要通过下文的显式续接创建新运行。

## 实际保存的内容

浏览器身份与会话元数据保存在外层 `data/browser-control/browser-state.sqlite`，Chromium 身份保存在 `data/browser-control/profiles/<profileId>`。任务结束只释放该任务的租约，关闭查看器不销毁浏览器身份。

关闭重开或控制器重启后，可显式恢复同一身份、最多 12 个安全网址标签、选中标签、cookie、localStorage 和各标签各自的 sessionStorage。同站点多个标签不再互相覆盖 sessionStorage。恢复完成后会移除启动恢复脚本，用户退出网站或清除数据后不会再次灌回旧快照。控制器重启后保持暂停，用户明确接管或交还后才执行操作。

本机页面偏好只保存工作区 ID、会话 ID 和缩放，不保存输入文字、网页地址或登录内容。浏览器前进/后退栈保留于当前 Chromium 进程；跨进程恢复网址会去掉 query/hash，不承诺重建完整导航历史。网站仍可要求重新登录。

截图与页面 revision 一致后才允许新的坐标点击，避免连续点击旧画面。服务失联时停止输入并显示断连状态；重新连接先核对服务器状态，恢复浏览器需要显式操作。

运行中的 agent 会定期续约浏览器占用。应用突然退出后，旧占用默认一分钟到期；后续任务可重新连接同一身份。正在执行的浏览器动作或控制权交接不会被抢占，重新连接也不会夺回用户的人控状态。

## 启动

在外层项目启动持久浏览器控制器：

```sh
cd /home/ubuntu/elsys
node server/browser-broker.mjs
```

另一个终端运行当前 Hyperagent 服务：

```sh
cd /home/ubuntu/elsys/hyperagents
npm run dev
```

应用启动时读取控制器的私有连接配置。先启动控制器再启动应用，可让聊天与工作台使用同一持久服务。

当前机器已达到文件监听数量上限，因此本轮已启动构建后的服务，入口为 `http://127.0.0.1:5173/browser`。这种启动方式不依赖开发文件监听：

```sh
npm run build
APP_PORT=5173 npm run preview
```

## 任务与 DCU

关闭聊天页不会取消服务器运行。服务重启后，中断任务可通过 **从已保存上下文继续** 建立关联的新运行，保留原目标、已记录步骤和当前实存产物，具体语义见 [任务续接](RUN-CONTINUATION.md)。旧审批不自动授权新动作，已准备但未落盘的产物也不显示为已保存。

SCNet 适配保留最近浏览器操作返回的会话 ID、观察 ID 和有界控件目录，使小模型可取得真实的下一步参数。当前模型输入预算较小，最多传入部分控件，容量不足会明确失败。DCU 作业有效期在聊天中显示，作业结束后任务、聊天和浏览器身份继续保存在本机。
